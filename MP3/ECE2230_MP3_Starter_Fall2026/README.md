# mp3
MP3: Five sorting algorithms and recursion

See MP3_Fall2026_Assignment.pdf on Canvas for the assignment requirements,
grading weight, and deadline.

## Getting started

Download the MP3 starter ZIP from Canvas and extract it into your MP3 working
directory on your Ubuntu machine. Use your completed MP2 program as the
starting point, as described in the assignment.

## Canvas submission

Submit one ZIP file to the MP3 assignment on Canvas containing:

- lab3.c
- ids_support.c
- llist.c
- datatypes.h
- ids_support.h
- llist.h
- makefile
- your test script (for example, mytestscript.sh; you may choose its name)
- a PDF of your test log, including the required performance graphs

Do not submit other files. You may make more than one submission; only the
final submission will be graded.

## Updated materials

If assignment files are updated, download the updated materials from Canvas.
