# MP1: Sequential List

See the MP1 assignment document on Canvas for the complete assignment requirements.

Download and extract the MP1 starter files from Canvas. Complete the assignment using the provided templates and tests.

## Submission

Submit **one ZIP file** to Canvas named:

`FirstName_LastName_MP1.zip`

For example:

`John_Smith_MP1.zip`

The ZIP file should contain **only** these four files:

- `lab1.c`
- `ids.c`
- `ids.h`
- `mytestinput` — your own input test script

Place these four files directly in the ZIP file; do not put them inside an additional folder.

From a Linux terminal, one way to create the ZIP file is:

```bash
zip FirstName_LastName_MP1.zip lab1.c ids.c ids.h mytestinput
```

Do **not** include the provided test files, expected-output files, README, grading scripts, or other starter files in your submission.

You may submit more than once on Canvas. Only the final submission will be graded.
